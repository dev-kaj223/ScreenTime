## Implemented scope

Packaging builds a self-contained win-x64 folder ZIP using pinned SDK 8.0.425/runtime 8.0.31, locked NuGet inputs, unique bounded staging and normalized archive metadata. Explicit files avoid native self-extraction and permit a complete SHA-256/module/license inventory. Output labels cannot overwrite existing candidates. The manifest distinguishes resolved dependencies/placeholder-free assets from byte-matching delivered files and the complete file list. Actual project/upstream and third-party license/NOTICE texts accompany the archive, including self-contained runtime/WPF/Windows Forms notices. Read-only CI uploads candidate artifacts for `screentime-dev`, without tag triggers or public-release steps.

`ScreenTimeDistribution=true` deliberately selects the new Production profile; ordinary builds stay Development, explicit tests remain isolated, legacy launch selection is rejected. Tests also reject real ScreenTime/Dev profile roots. Autostart remains disabled. A fresh production profile defaults its configurable shortcut to Ctrl+Alt+S while honoring saved values; development retains its separate shortcut. The read-only `--describe-runtime` seam resolves paths and reports included framework/native versions and module locations before logging/storage/registration; failures use stderr/nonzero exit without opening a real profile. Actual runtime smoke always uses disposable Test profiles.

The minimum servicing update is Microsoft.Data.Sqlite 8.0.0 → 8.0.31, resolving SQLitePCLRaw 2.1.12. Fresh advisory audit is mandatory and cannot be suppressed. The experimental extracted native module reports SQLite 3.53.3, above the advisory minimum 3.50.2. No policy, schema, grace authority, deadline duration, process targeting or passive rendering code changes were made. .NET 8's 2026-11-10 end-of-support is recorded for later release decisions.
